# Принятая основа кота: B3-refined

Решение пользователя: «Пока оставляем эту модель». Зафиксировано 2026-09-10.

B3-refined.blend — точная копия показанного пользователю Blender-исходника.
Контрольные рендеры: B3-refined-three-quarter.png и B3-refined-front.png.
Воспроизводимый генератор: ../build_b3_refined.py.

Дальнейший редизайн внешности отложен. Сохранять силуэт, мордочку, окрас и мягкость шерсти при адаптации к игре. Это статическая высокополигональная основа без рига; принятие внешности не означает готовность игрового экспорта.

Текущий rig_cat.py привязывает целые отдельные примитивы к костям и создаёт новые передние лапы. Для этой объединённой анатомической сетки такой вызов напрямую непригоден: он оставит неподвижные лапы тела и добавит лишние. Нужны веса существующей геометрии и перенос тех же весов на шерсть. Сначала проверить посадку, ходьбу и царапание в отдельном экспорте; затем заменять игровой ассет.
