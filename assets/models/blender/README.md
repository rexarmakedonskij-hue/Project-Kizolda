# Blender source assets

`office.blend` and `cat.blend` are editable sources generated by `build_mvp.py` with Blender 5.2.1. Materials and geometry are original procedural work for this project.

The script takes gameplay coordinates (Godot: X right, Y up, forward -Z), converts them to Blender Z-up, and exports GLB with Y-up. Dimensions are in metres. Run from the repository root; exports go to `assets/models/glb/godot_mvp/`.

The office includes a rounded oak desk with four legs, drawer and raised shelf. This replaces the previous technical blockout in the active room. Legacy assets are preserved separately.
