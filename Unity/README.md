# Pawductivity — Unity MVP

## Запуск

1. В Unity Hub добавьте эту папку `Unity` как проект и откройте в Unity 2022.3 LTS.
2. Дождитесь импорта и компиляции скриптов.
3. Откройте `Assets/Pawductivity/Scenes/Main.unity`.
4. Нажмите Play, затем **Начать смену** в окне Game.

Комната, кот и интерфейс создаются при запуске. До Play в сцене виден только объект Pawductivity — это ожидаемо.

## Механики

- Смена длится 40 секунд; нажатие F добавляет 5% к квоте, максимум 100%.
- Первый кот приходит через 4 секунды, последующие — через 5–9 секунд после ухода предыдущего.
- У кота есть 5 секунд до повреждения обоев на 10%. После повреждения кот уходит.
- Мышь поворачивает взгляд сидящего за столом игрока. Пробел прогоняет кота, если скалярное произведение направления взгляда и направления на кота больше 0.88 — как в исходном MVP.
- Победа: закончить смену с квотой 100% и повреждениями ниже 50%.
- Esc ставит игру на паузу и освобождает курсор. Потеря фокуса также ставит паузу.
- После завершения смены R или кнопка запускают новую смену.
- Русский HUD показывает время, квоту, ущерб и таймер кота. Есть звуки работы, кота, царапания и распылителя.

Комната и кот собраны из Unity-примитивов. Использованы три исходные текстуры обоев. Исходные GLB не импортируются: проект не требует стороннего glTF-пакета. Все звуки синтезируются локально при запуске.

## Проверки и сборка

Меню **Pawductivity → Validate game rules** выполняет 13 проверок: квота и её предел, таймеры, видимость, прогон, удаление кота после царапания, отсутствие повторных повреждений, победа/поражение, заморозка результата и независимость от длительности кадра. Ошибка приводит к исключению в Console.

Меню **Pawductivity → Build macOS / Build Windows** проверяет правила и собирает приложение в `Builds`. Нужен соответствующий модуль Build Support в Unity Hub.

Для CI с установленным Unity:

```sh
"$UNITY_EDITOR" -batchmode -nographics -quit -projectPath "$PWD" -executeMethod Pawductivity.Editor.BuildTools.Validate -logFile validation.log
"$UNITY_EDITOR" -batchmode -quit -projectPath "$PWD" -executeMethod Pawductivity.Editor.BuildTools.BuildMac -logFile build.log
```

## Статус проверки

Структура проекта, ссылки GUID, JSON зависимостей и наличие ресурсов проверены локально. Unity Editor и C#-компилятор на машине создания отсутствуют: компиляция, 13 проверок в Unity, визуальная проверка и сборка приложения **ещё не выполнялись**.

Проверить в редакторе: старт и захват мыши; поворот в обе стороны; успешный и неуспешный прогон; повреждение и смену текстуры; паузу с активным котом; победу с квотой 100%; проигрыш по квоте; повторный запуск; звук и масштабирование окна.

Баланс сохранён из исходного MVP. При смене 40 секунд и одном коте одновременно ущерб не успевает достичь 50% (максимум четыре повреждения). Порог поражения по обоям оставлен в правилах, но для его достижимости понадобится отдельное решение о балансе.
