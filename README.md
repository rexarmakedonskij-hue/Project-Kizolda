## Основной движок — Godot

Решение от 6 сентября 2026: дальнейшую разработку Pawductivity ведём на **Godot 4.x**, используя проект `project.godot` в корне репозитория.

Папка `Unity/` сохранена как архив экспериментального переноса. Она не является активной версией игры. Возвращаться к Unity следует только по отдельному решению пользователя.

Первый прототип мультяшного 3D-симулятора удалённой работы с котами.

## Запуск

1. Установите Godot 4.x с [официального сайта](https://godotengine.org/download/).
2. Откройте в Project Manager папку этого репозитория.
3. Нажмите **Run Project** (`F5`).

## Управление

- Мышь — осмотреться, не вставая из-за стола.
- `F` / `Tab` — открыть ноутбук или вернуться к осмотру комнаты.
- Мышь в ноутбуке — выбрать ответ, затем нажать «Отправить».
- `Пробел` — погладить сидящего на клавиатуре кота; у чашки и обоев — прогнать. Смотри на кота перед действием.
- `E` — убрать пролитый кофе (2,5 секунды); F или пробел прерывает уборку.
- `Esc` — пауза и освобождение курсора.
- `R` на экране результата — новая попытка.

Текущая тестовая смена длится 150 секунд. Нужно правильно обработать пять писем (+20% за каждое). Первое письмо доступно сразу, следующие поступают через каждые 25 секунд смены. Выбранный ответ сохраняется, если отвлечься на кота. После отправки и появления следующего письма переходите к нему кнопкой.

Первое событие начинается через 8 секунд. События чередуются: клавиатура → чашка → обои. Между уходом кота и следующим появлением — 8–12 секунд. Перед прыжком есть 3 секунды предупреждения; чашку кот трогает ещё 3 секунды до проливания. Уборка занимает 2,5 секунды. У обоев предупреждение длится 4 секунды, затем кот наносит 10% ущерба каждые 5 секунд. При 50% повреждений смена проиграна. Значения предварительные, до пользовательского теста.


## Готово в Godot MVP

- Кабинет смоделирован в Blender; активный персонаж — импортированный Lowpoly Cat + Run Animation от Daily Lowpoly (CC BY 4.0), адаптированный к ходьбе и царапанию в Godot.

- Игрок сидит за столом; перемещение и дополнительные уровни в этот MVP не входят.

## Экспорт

Пресет `macOS` в `export_presets.cfg` перечисляет игровые ресурсы, включая загружаемые из скриптов. Архив Unity, Blender-исходники, документация и тесты исключены.

Проверенный экспорт данных (это ещё не самостоятельное приложение):

```sh
mkdir -p builds
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --export-pack macOS builds/Pawductivity-data.zip
```

После установки шаблонов **4.7.2.stable** сборка приложения:

```sh
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --export-release macOS builds/Pawductivity.zip
```

Пресет предназначен для локальной проверки; подпись и нотариальная проверка публичного релиза не настроены. Шаблоны установлены. Windows ZIP первой итерации: `builds/Pawductivity-Windows-x64-iteration1.zip` (около 40 МБ), ранее загружен в разрешённую пользователем папку Яндекс Диска. Тогда запуск Windows EXE на Windows ещё не был проверен; актуальная сборка проверена нативно. macOS ZIP: `builds/Pawductivity-macOS-iteration1.zip`; содержит приложение, инструкцию и лицензию. Выполнена локальная ad-hoc подпись, проверены запуск без графики и загрузка ресурсов с графическим движком на Apple M3 Pro. Окно закрыл пользователь; запуск с аргументом `--script` не дал результатов автотестов и не засчитывается как их прохождение. Полноценное прохождение экспортированного macOS-приложения ещё предстоит.

Windows-экспорт: `Godot --headless --path . --export-release "Windows x64" builds/windows/Pawductivity.exe`. Упаковывайте EXE с инструкцией и лицензией из `builds/windows/` в ZIP.
