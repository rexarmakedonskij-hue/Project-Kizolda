# Pawductivity — MVP

Первый прототип мультяшного 3D-симулятора удалённой работы с котами.

## Запуск

1. Установите Godot 4.x с [официального сайта](https://godotengine.org/download/).
2. Откройте в Project Manager папку этого репозитория.
3. Нажмите **Run Project** (`F6` / `F5`).

## Управление

- Мышь — осмотреться, не вставая из-за стола.
- `F` — выполнить часть рабочей квоты.
- `Пробел` — прогнать кота, когда он находится в поле зрения.
- `Esc` — освободить курсор.

У кота есть пять секунд до следующего повреждения обоев. При 50% повреждений смена проиграна.
