# Запуск Pawductivity в Windows

1. Рабочий проект — `D:/Pawductivity/Main/UnityGame`.
2. Использовать Unity `6000.3.25f1`; точная версия записана в `UnityGame/ProjectSettings/ProjectVersion.txt`.
3. Открыть проект в Unity, дождаться импорта и компиляции.
4. Открыть `Assets/Pawductivity/Integration/Scenes/FripouilleLaptop.unity` и нажать Play.

Инструкции, текущие проверки и ограничения находятся в актуальных `AGENTS.md`, `UnityGame/AGENTS.md` и документах `docs/workstreams/` на D.
Архив `Unity/` требует отдельной версии редактора из собственного `ProjectSettings/ProjectVersion.txt`.
Новая сборка хранится локально; загрузка требует отдельного явного запроса пользователя.
