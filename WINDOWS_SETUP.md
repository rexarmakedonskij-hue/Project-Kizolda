# Project Kizolda / Pawductivity — запуск на Windows

## Получение проекта с GitHub

Установите Git for Windows и Git LFS. Для приватного репозитория нужен доступ
к аккаунту или выданное владельцем разрешение. В PowerShell выполните:

```powershell
git lfs install
git clone https://github.com/rexarmakedonskij-hue/Project-Kizolda.git
Set-Location Project-Kizolda
git lfs pull
```

Откройте `project.godot` в Godot 4.7.2 stable, дождитесь импорта ресурсов и
нажмите F5. Модели должны быть загружены Git LFS до импорта.
Сборки и результаты прошлых проверок сохраняются локально и не входят
в репозиторий. Описание ZIP ниже относится к прежнему способу передачи проекта.

### Сообщение про post-checkout при клонировании

В установленной связке Git for Windows 2.45.1 и Git LFS 3.5.1 проверка
клонирования завершилась сообщением `active post-checkout hook found`.
Это стандартный локальный хук, который создаёт Git LFS. Файлы проекта и
моделей при этой проверке уже были загружены полностью.

Если после такого сообщения создана папка клона, перейдите в неё и выполните:

```powershell
Set-Location Project-Kizolda
git lfs pull
git lfs fsck
git status --short
```

При успешной проверке LFS и пустом списке изменений можно открывать проект
в Godot. Этот способ проверен на повторной загрузке репозитория с GitHub.

## Быстрый старт

1. Полностью распакуйте ZIP, например в `C:\Projects\Project Kizolda`. Не запускайте проект прямо из архива.
2. Установите стандартную версию Godot для Windows x64. На исходной машине используется **Godot 4.7.2 stable**; `project.godot` помечен версией 4.7. Для воспроизведения окружения используйте ту же версию. Версия .NET не требуется: игра написана на GDScript.
3. Запустите Godot, выберите **Import**, укажите `project.godot` из распакованной папки и откройте проект.
4. Дождитесь завершения первого импорта ассетов. Папка `.godot` намеренно отсутствует в архиве и будет создана заново.
5. Нажмите **F5** (Run Project). Основная сцена — `main/main.tscn`.

Для запуска игры не нужны Node.js, Python, Unity или Blender. Игра использует готовые GLB/FBX. Исходники Blender сохранены для редактирования; в их каталоге сохранён `.gdignore`, отключающий автоматический импорт. В README зафиксирована версия Blender 5.2.1 для работы с моделями.

## Запуск и проверки из PowerShell

Укажите реальный путь к распакованному исполняемому файлу Godot (желательно варианту с консолью):

```powershell
Set-Location 'C:\Projects\Project Kizolda'
$Godot = 'C:\Tools\Godot\Godot_v4.7.2-stable_win64_console.exe'
& $Godot --headless --editor --path . --import
& $Godot --path .
```

После импорта можно запустить существующие проверки:

```powershell
& $Godot --headless --path . --script tests/mvp_test.gd
& $Godot --headless --path . --script tests/route_test.gd
& $Godot --headless --path . --script tests/scratch_test.gd
```

## Сборка Windows EXE

В Godot установите Export Templates, точно соответствующие версии редактора, через **Editor → Manage Export Templates**. В `export_presets.cfg` уже есть пресет **Windows x64**.

```powershell
New-Item -ItemType Directory -Force 'builds/windows' | Out-Null
& $Godot --headless --path . --export-release 'Windows x64' 'builds/windows/Pawductivity.exe'
```

При передаче сборки сохраните атрибуцию и лицензию кота из `assets/third_party/daily_lowpoly_cat/` вместе с EXE.

## Git и состав архива

Включены полная локальная папка `.git` с историей, индексом и ссылками, текущее рабочее дерево, изменённые и ещё не добавленные в Git файлы. На момент подготовки исходная история содержит 4 коммита, HEAD — `2905a81`. Новые коммиты при упаковке не создавались. Для работы с историей установите Git for Windows; для запуска игры Git не требуется.

```powershell
git status --short
git log --oneline -5
git fsck --full
```

Изменения в `git status` ожидаемы: это текущая работа, которую нужно сохранить. Не выполняйте `git reset --hard` или `git clean`, если хотите её оставить.

Сохранены игровые ресурсы, лицензии, тесты и результаты проверок, документация, исходники моделей и архив экспериментального проекта `Unity/`. Активный проект — Godot в корне; Unity устанавливать не нужно.

Исключены `node_modules`, `.venv`/`venv`, кеши Godot/Python/инструментов, служебные файлы Finder и корневая папка `builds/` с прежними экспортами. `.import`, `.uid`, `.gdignore` и Unity `.meta` сохранены как метаданные исходных ресурсов. Git-объекты сохранены без переписывания истории, поэтому ранее закоммиченные файлы остаются в истории независимо от фильтров рабочего дерева.

## Управление и ограничения проверки

- Мышь — осмотр комнаты; в ноутбуке — выбор и отправка ответа.
- **F / Tab** — открыть или закрыть ноутбук.
- **Пробел** — прогнать кота в поле зрения.
- **Esc** — пауза и освобождение курсора.
- **R** на экране результата — повторная попытка.

ZIP подготовлен на macOS. Целостность архива и сохранность исходников/Git проверяются при упаковке; нативный запуск на Windows в рамках подготовки архива не выполнялся. Старые результаты тестов в `tests/results/` относятся к предыдущим проверкам и не являются проверкой Windows.
